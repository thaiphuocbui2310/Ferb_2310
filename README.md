# Bui Thai Phuoc — Personal Portfolio

🌐 **Live:** [https://thaiphuocbui.github.io/portfolio](https://thaiphuocbui.github.io/portfolio)

A clean, responsive personal portfolio website built with pure **HTML, CSS & JavaScript** — no frameworks, no build tools required.

---

## 👨‍💻 About

Final-year **Control and Automation Engineering** student at Danang University of Science and Technology (DNUT), Vietnam. Passionate about FPGA design, embedded systems, and hardware development.

---

## 🚀 Features

- ⚡ Dark theme with cyan/purple gradient accents
- ✍️ Typewriter animation in Hero section
- 🎞️ Scroll reveal animations
- 📱 Fully responsive (mobile-friendly)
- 🔗 Active nav highlight on scroll
- 🍔 Hamburger menu for mobile
